# Le Tableau

Une application Windows simple pour suivre les tâches du bureau à plusieurs, avec un tableau commun dans un dossier partagé sur le NAS.

## Télécharger

[Télécharger la dernière version Windows](https://github.com/wood51/le-tableau-releases/releases/latest/download/LeTableau-Windows.zip)

Extraire le ZIP et conserver le dossier complet **LeTableau** sur chaque PC, par exemple sur le Bureau. Ouvrir **LeTableau.exe**. Le guide PDF illustré est dans ce dossier. Python et un compte GitHub ne sont pas nécessaires pour utiliser l’application.

Si Le Tableau est déjà installé en version 1.1.0 ou suivante, cliquer sur **Mettre à jour** dans l’application. Le logiciel se ferme puis se rouvre. Faire la mise à jour sur chaque poste ; les tâches et les réglages sont conservés.

## Version 1.3.0

- **Couleurs des personnes** : dix couleurs au choix dans les paramètres, avec aperçu du badge.
- **Catégories libres** : un nom par ligne dans les paramètres, un choix facultatif par tâche et un filtre sur le tableau.
- **Menu des documents** : une icône de fichier avec compteur regroupe tous les fichiers et dossiers liés. Les originaux restent à leur emplacement ; seuls les chemins sont enregistrés.
- Conservation du tableau unique, des quatre colonnes, de l’urgence, de la corbeille et des sauvegardes périodiques.

Les catégories et couleurs sont partagées entre les postes. Le guide PDF est conservé sans modification dans cette version.

## Où sont les tâches ?

Les tâches restent dans le dossier commun que vous choisissez, par exemple sur votre NAS. Ce dépôt contient uniquement les versions du logiciel à télécharger. Aucun tableau ni fichier utilisateur n’y est publié.

Un seul tableau commun, une copie du logiciel sur chaque PC. Aucun serveur à installer. Internet est nécessaire pour télécharger et mettre à jour le logiciel ; les tâches passent par votre partage réseau local.

Les notices des composants Python, PySide6, Qt et PyInstaller accompagnent le logiciel. Les textes des licences sont fournis dans le dossier **Licences**.
